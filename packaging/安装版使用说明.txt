求职避坑镜 0.3.1 — Windows 安装版

1. 双击安装包，选择安装位置并完成安装。无需另外安装 Python。
2. 首次启动需要联网下载 Qwen3-Embedding-4B（约2.5GB）；下载中断可重试。建议至少8GB可用磁盘、16GB内存。
3. 进入应用设置，填写你自己的 DeepSeek API Key。也可填写安装目录.env中的DEEPSEEK_API_KEY后重启；界面保存的Key优先。模型接口费用由该账号承担。
4. 可以输入文字、PDF或图片。普通聊天只进行追问或简要分析；明确要求生成报告时才生成 Word 报告。
5. 本机用户数据目录：程序安装目录（JobMirror.exe所在目录）。安装包不包含制作人员的API Key、聊天记录、上传文件或报告。
6. 卸载前请先关闭软件。卸载时可以选择一并删除模型、聊天记录、附件、设置和日志；选择保留时，这些数据会继续留在原安装目录。需要删除单个会话可在应用内删除。
7. 安装包会检查 Microsoft Edge WebView2 Runtime；缺少时会通过微软官方引导程序联网安装。安装失败时可从微软官网手动补齐：https://developer.microsoft.com/microsoft-edge/webview2/
8. 包含CPU及Vulkan模型运行支持；显卡是否能加速取决于驱动，无法使用显卡时会采用CPU。

故障日志：安装目录\logs。
