# 第三版反馈与报告导出修复（2026-10-08）

## 原因与修改

标题下面的半句话来自前端截取 22 字的会话标题，原导出把会话标题当成报告副标题。这不是事实摘要。本次改成完整固定副标题，并新增“分析材料与用户说明”，保存并展示各报告版本对应的完整原始输入和附件名称；用户说明与经核验事实明确区分。旧版本下载仅回溯到该报告生成时，不能带入后续用户信息。

更新法律原文到全国人大国家法律法规数据库具体记录，区分法律制定机关与网页载体。五部门风险提示改用人社部原始发布页，并保留官方备用页面；浏览器已打开两页。典型案例采用人社部主办网站官方发布页，团队整理资料明确标注整理者和关联原文。仅更新来源元数据，401 条资料向量复用，不改变证据正文。历史报告下载仅在证据正文一致时刷新来源元数据，原报告不被修改。

Word 设置真实超链接、链接样式与中文 URL 编码；添加企业信用与人社官方核查入口；同一官方文档的发布机构和地址合并展示，但保留每个来源编号及完整法条/案例文本。正文可自然分页，灰色表格边框，去除标题继承的蓝色横线。本次并非对所有网页或手机客户端做兼容保证。
