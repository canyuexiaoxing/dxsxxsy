# 就业避坑与独立复核验证记录（2026-10-08）

## 产品重点
帮助大学生在找实习、找工作、付款和签约前识别招聘主体、费用、贷款、培训协议及拟签合同中的实际风险。输出暂停事项、独立核查渠道和退出信号。纯信息缺口不单列为风险，未来可能出现的异常仅作为预防提醒；未入职场景不自动转成离职索赔方案。

## 本次修改
- 就业阶段、风险分组、法律适用、追问与建议由模型判断；程序负责检索执行、引用和格式校验、存储、轮次与导出。
- 分析与复核上下文独立。复核检查阶段、事实、新旧材料、风险重复、法律依据、建议及交付内容，指出具体原句和修改方向。
- 强化新旧材料区分；HR补充说明不能证明新版合同原文已经修改。未知接触商业秘密不能推断为已经接触或大概率不接触。
- 校准试用期工资规则中的“或者”与数字比较，避免将正常约定误报为风险；仍保留适用最低工资未知的核查事项。
- 检索依赖不可用时显示具体原因，不保存缺少成功检索支持的新报告。
- 只清除模型误放在外层的完整空引用占位组合，真实引文或不完整字段仍严格校验。
- 审核最多两次、审核后修改最多两轮。审核调用失败也占用次数。最后修改未再复核时如实显示，不误写为通过或已修改两轮。

## 验证结果
168项后端回归测试通过，4项前端打包检查通过，前端构建通过。两组详细模拟材料使用真实模型API和本地RAG检索完成分析、补充材料修订及后续问答。它们不是实际受害案件，也不是与判决结论对照的评测。

### 实习招聘与收费任务
未付款、未签约学生收到垫资返佣任务。补充材料显示公司官方渠道否认授权；联系人撤回充值要求，改收699元证明服务费。
最终报告聚焦未经确认的招聘主体和当前服务费；旧充值要求仅保留为背景，不再重复作为当前独立风险。给出停止付款、独立核实及退出建议。普通追问没有新增报告版本，当前报告为第2版。

### 入职前劳动合同与培训约定
拟签三年合同、六个月试用期；正式工资7000元、试用工资5600元，同岗位最低档6000元。培训违约金、工资直接扣除及竞业范围先后收到补充修改。
额外纠错测试纠正5600与7000×80%、6000×80%的比较。最新正文不将正常试用期工资条件列为风险，提醒仍需确认适用最低工资；重点核实竞业范围与实际涉密情况。普通追问未新增版本；随后明确纠错请求生成第3版。
该纠错轮第一次审核返回格式异常，第二次审核发现数字比较错误，分析Agent修改一次后交付。达到两次审核上限，状态为final_revision_unreviewed，未进行第三次审核，也未显示审核通过。人工阅读最终正文确认上述比较已修正，但不改变自动审核状态。
