# 事实表与固定内容验证

本次改动沿用分析Agent、独立复核Agent和两次审核上限，不新增人工操作步骤。重点是大学生在找实习、找工作、付款、接受录用和签约前规避风险。

## 事实如何进入分析
生产ChatModel先独立提取FactLedger。输入仅为当前用户说明和用户/上传材料原句目录，不使用知识库案件、旧助手回答或旧报告。提取结果区分known、unknown、inferred；known表示用户陈述，不代表已经外部核实。已知和推测需引用原句编号，推测还需说明不确定性。

程序校验结构、原句编号、数量和上下文预算，回填原文出处，最多尝试两次。失败时不生成新报告、不写入新的会话消息。程序不根据关键词判断事实真伪或风险类型。

经过原句校验的事实表传给分析Agent和复核Agent；两边仍收到原材料。事实表可能被模型整理错，因此复核必须独立回看原文，不能只对照事实表放行。每个成功用户回合重新整理，以当前明确纠正为准，保存到会话fact_ledgers；历史事实表不直接当作新事实。记录可重启后保留。

## 行动建议与报告
明确区分已知分期与确认借款；核查账户、登记、机构资质和书面协议不能当作岗位安全或付款许可。招聘转收费培训时，建议优先暂停与岗位获取挂钩的培训付款和借款；独立培训消费另行评估。未知信息保留为待核实，不强迫用户重复回答已经说不知道的问题。

首份交付报告的change_reason固定为空；内部审核修改不等于用户报告修订。网页、Word和Markdown导出不显示第1版的修改说明，旧报告重新导出也遵循此显示规则；原有历史报告正文不被重写。

## 固定验证材料
knowledge/evaluations/content-regression-cases.json包含8类模拟材料：招转培且贷款未知、正常免费培训、确认借款、撤销培训收费、录用前押金、个人聊天账号、拟签证件保管条款、缺少材料的普通咨询。每类包含必须表达和禁止出现的结论。

tools/run_content_bench.py调用实际模型API和本地RAG，输出完整消息、事实表、报告与审核轨迹。它自动检查接口流程是否完成；内容结论由人工依据must/must_not核对，不使用线上关键词裁决，也不把审核passed等同内容正确。

运行需配置模型API和启动本地Embedding；不打印密钥。可通过--case选择案例，--output保留不同轮次结果；已有验证结果不会由日常用户流程读取。程序测试中的旧FakeModel仍兼容原流程，生产ChatModel始终执行事实提取。

## 验证限制
事实提取增加一次模型调用，格式或引用异常最多重试一次，因此比旧流程增加耗时及调用成本。统一事实表、提示词和回归测试都不能保证模型永不误判；两个Agent目前仍使用同一个配置模型。完整内容验收结果见本轮实际输出记录。

## 本轮实际验收结果

181项后端回归测试通过，4项前端打包检查通过，前端构建成功，更新后服务健康检查正常。测试使用模拟材料和实际模型API，不能冒充真实判决验证。

| 场景 | 最终结果 | 自动复核状态 |
| --- | --- | --- |
| 用户给定的9800元培训信息 | 合并为1项招转培风险；分期性质未知；复核发现付款时点被扩写，最后稿明确时点待核实；首版不显示修改说明 | 两次审核、两次修改，最后修改未再复核 |
| 明确公司承担费用的免费培训 | 0项风险，未知信息保留为核查事项，不承诺岗位安全 | 1次审核通过 |
| 明确12800元借款页面 | 2项风险：付费培训捆绑、实际借款安排；保留12期、总还款14560元与未签约未付款状态 | 2次审核、1次修改后通过 |
| 公司书面撤销5000元收费 | 首稿识别收费风险，补充后删除原风险，修订稿0项风险；没有把核查事项重新计为风险 | 修订稿2次审核、1次修改后通过 |

内容不是全部无误：9800元报告limitations仍将广告中的“培训后安排工作”称为“口头承诺”，与用户给定来源不完全一致。这是人工阅读发现的残留来源措辞错误，不能用其他正确字段或审核状态掩盖。当前事实表与复核流程已实现，但不保证每次输出完全准确。

最终版本输出分别在knowledge/evaluations/fact-ledger-accepted-20261008与fact-ledger-accepted-controls-20261008；人工验收汇总在knowledge/evaluations/fact-ledger-content-inspection-20261008.json。每份JSON保留实际输入、完整最终报告、事实表和审核轨迹。早期依赖失败及内容失败轮次保留在fact-ledger-20261008、fact-ledger-verified-20261008、fact-ledger-final-20261008，不能用它们替代当前结果。

固定库另有押金、个人聊天账号、拟签证件保管条款和信息不足咨询4类，本轮未调用真实API，不计为内容验收通过。后续可以复用相同测试脚本，不必为每个新例子临时改变验收口径。

审核格式兼容仅放宽诊断标题、定位标签与code命名，完整七项检查、具体detail、风险索引和来源编号等约束继续保留。生产分析必须显式给出阶段和非空判断理由，遗漏先结构修复，程序不猜阶段。
