# 模型判断与内容复核流程

2026-10-08按用户确认调整：内容理解与合理性判断由分析Agent和复核Agent完成；程序保留技术检查。审核最多2次、基于审核的修改最多2轮，未通过仍交付当前可用报告。

## 已停用的运行规则
AgentEngine不再调用detect_stage、normalize_layout、normalize_preemployment、prevention_issues、context_sources、prepare_report或prepare_prevention。旧帮助函数保留兼容既有测试，不参与实际用户流程。
因此运行中不再按关键词决定就业阶段、合并或删风险、删贷款或报警建议、改写摘要和修改原因、添加语义自查问题或固定补齐法条，也不再用法条编号配关键词判断法律适用。

## 分析Agent
search_knowledge工具的stage由模型结合用户真实经历给出。合同里的“离职后”不证明已入职，未知阶段用unknown。最终输出employment_stage、stage_reason；报告里的预防行动prevention及自查问题self_checks也由模型生成。
程序执行模型的检索请求，保留向量及关键词混合检索、分类预算和来源显式关联。知识库标签用于检索组织，不当作用户事实。

## 复核Agent
独立上下文，不读取分析Agent聊天输出或推理，只接收用户材料、用户历史消息、当前消息、旧报告和待审草稿及RAG依据。模型开启推理，输出预算32768；最多两次审核，包括失败重试。
审核必须完成stage、facts、updates、risk_grouping、legal_basis、advice、delivery七项，并提供具体核对结果及issues。检查所有自然语言字段，尤其limitations中的缺失断言；机器字段本身不是正文外露，用户消息是合法原句来源，有条件的未来风险提醒不是已发生事实。
允许措辞、排版及合理等级差异，不追求诉讼完备性；不放过明确事实扩写、已给信息被遗漏、同笔交易重复计数或新旧判断矛盾。审核意见返回分析Agent修改，不直接重写用户报告。

## 程序保留的职责
JSON结构和取值、工具参数、原句及页码、引用编号确已检索、动作和版本合法性、轮次与超时、敏感信息格式、会话保存、显示与Word导出。正文中的来源编号转换为可读名称属于展示，不进行内容裁决。
review_status、review_notes由程序独立生成，不混入模型的limitations；网页和Word单独保留系统说明，避免模型复制旧状态。复核异常trace记录异常类型、安全原因和格式错误位置，不记录API密钥。
