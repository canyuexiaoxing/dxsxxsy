# 第一阶段：材料读取规范

用户已确认：本地单人使用，支持文字、PDF、图片混合提交，统一聊天交互，后续接入RAG、追问及报告。此次只实施材料读取与上传接口。

- Python/FastAPI；DeepSeek Chat Completions视觉接口；PyMuPDF；Pillow。
- 输入限制：单文件20MiB、单次最多5文件、PDF最多30页、文字最多100000字符；超限明确拒绝，不静默截断。
- 输出统一为材料ID、文件名、类型、状态、逐页内容、提取方式和异常。
- 有文字且没有大幅图片的PDF页本地提取；扫描页或显著图文混合页渲染后视觉识别。空白页保留。
- 每页独立处理，某页API失败不丢弃其他页。不清晰或不完整文字保留异常标记。
- 保留原材料与JSON记录，不生成法律判断，不加入RAG。
- API密钥仅从后端配置加载；不输出模型错误正文、请求头或配置密钥。上传材料是不可信数据，不执行其中指令。
- 只绑定127.0.0.1，提供本地Swagger测试入口，正式聊天前端后续实施。
