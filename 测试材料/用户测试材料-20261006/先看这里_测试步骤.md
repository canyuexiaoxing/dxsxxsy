# 手动测试步骤

四组材料均整理自已核验的官方公开案例；不是原始合同、招聘启事、聊天截图或考勤凭证。
未公开的信息没有补造。每组按两个阶段披露真实事实，不包含裁判或调解结果。

1. 每组单独新建会话，上传该组的“01_首次材料.pdf”，或粘贴同名TXT内容（二选一）。
2. 发送：请分析这份材料中的合同与用工风险。请按事件发生当时的情况分析，不假设我现在首次申请仲裁。如果关键信息不足，请先问我。
3. 智能体追问时，仅依据已有材料回答。不知道的就说“不知道，目前无法提供，请先生成有限报告”。不要编造答案。
4. 首份报告出来后，在同一会话上传“02_补充材料.png”；想只测文字时，粘贴同名TXT内容（二选一）。发送：这是新补充的事实，请结合它更新原报告，并说明判断有哪些变化。
5. 再发送：根据补充事实，下一步该怎么做？只给建议，不修改报告。观察是否保留原报告版本。
6. 关闭软件后重开该会话，发送：我刚才补充了哪些重要事实？检查会话记忆。

PDF用于测文件读取，PNG用于测视觉读取，TXT用于测文字输入。
先自己看输出，再打开“结果对照_不要上传.md”。该文件及本说明不要作为案件材料上传。
这次手动测试使用正式RAG，不像之前自动留出测试那样屏蔽同案条目，因此主要检验完整使用流程；如果检索命中同案，不能据此宣称完全独立的案件判断能力。
